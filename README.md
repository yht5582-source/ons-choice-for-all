# ons-choice-for-all

中國醫藥大學北港附設醫院「全病患臨床營養評估與院內配方動態試算系統」的單頁前端工具。此專案以 `index.html` 呈現臨床營養與院內 ONS / 管灌配方試算介面，協助依據病人基本資料、照護場景、疾病需求與院內營養品項，快速估算每日熱量與蛋白質供應量。

目前專案已部署於 GitHub Pages：

<https://yht5582-source.github.io/ons-choice-for-all/>

## 專案內容

此 repository 目前包含兩個檔案：

- `index.html`：完整的單頁應用程式，內含 HTML、CSS 與 JavaScript 計算邏輯。
- `README.md`：專案說明文件。

專案未包含 package manager 設定檔、建置流程或後端程式；目前是純靜態網頁。

## 主要功能

- 輸入個案基本資料：年齡、性別、身高、實際體重。
- 自動計算：
  - 理想體重（IBW）
  - BMI
  - 建議每日總熱量（TEE）
  - 建議每日蛋白質需求
- 選擇臨床條件：
  - 一般病房、ICU / 外科創傷、社區 / 門診
  - 鼻胃管灌食、經口進食、PEG / J-tube
  - 一般均衡、糖尿病、CKD 未透析、HD / PD 透析、腫瘤 / 癌症惡病質、傷口修復 / 手術後
- 選擇院內指定主營養品項，並輸入每日使用量。
- 選填蛋白質模組或熱量模組，進行跨品牌模組組合試算。
- 顯示熱量與蛋白質供應量、目標達成率與動態臨床提示。
- 提供院內口服 / 管灌營養品速查表。
- 提供三組快速載入範例：
  - 一般管灌個案
  - 透析 / 白蛋白偏低個案
  - CKD 未透析低蛋白個案

## 計算邏輯摘要

`index.html` 內建的 JavaScript 目前使用下列邏輯：

- 理想體重（IBW）
  - 男性：`(身高 - 80) * 0.7`
  - 女性：`(身高 - 70) * 0.6`
- BMI：`實際體重 / 身高(m)^2`
- 建議每日總熱量（TEE）：`IBW * 30 kcal`
- 蛋白質目標：依疾病類型調整每公斤 IBW 需求
  - 一般均衡、糖尿病：`1.0 g/kg`
  - CKD 未透析：`0.7 g/kg`
  - HD / PD 透析：`1.2 g/kg`
  - 腫瘤 / 癌症惡病質、傷口修復 / 手術後：`1.5 g/kg`
- 營養供應量：主營養品項、蛋白質模組、熱量模組的熱量與蛋白質加總。
- 達成率：實際供應量除以計算出的目標值後四捨五入為百分比。

## 院內品項資料

營養品與模組資料目前直接寫在 `index.html` 的 JavaScript 物件中，包括：

- 主營養品資料：`productsDB`
- 蛋白質模組資料：`proteinModulesDB`
- 熱量模組資料：`calorieModulesDB`

畫面下方的 Hospital Catalog 表格也以靜態 HTML 呈現醫令碼、品名、規格、熱量、蛋白質與臨床定位。

如需調整品項、熱量或蛋白質資料，請同步確認下列位置：

1. 下拉選單中的顯示文字
2. JavaScript 資料庫物件
3. Hospital Catalog 表格

## 使用方式

### 線上使用

開啟 GitHub Pages 網址：

<https://yht5582-source.github.io/ons-choice-for-all/>

### 本機使用

此專案目前不需要安裝相依套件或執行建置流程。下載 repository 後，直接以瀏覽器開啟 `index.html` 即可使用。

> 注意：頁面使用 Font Awesome CDN 載入圖示；若完全離線使用，圖示可能無法顯示，但主要試算邏輯仍在本機 `index.html` 中。

## 維護注意事項

- 這是單頁靜態工具；主要邏輯集中於 `index.html`。
- 目前沒有自動化測試、版本化資料檔或後端 API。
- 修改臨床公式或品項資料時，建議由臨床與營養專業人員再次核對。
- 若未來品項清單持續擴充，可考慮將產品資料從 HTML 中拆出為獨立 JSON 或資料檔，降低同步維護成本。

## 臨床使用聲明

本工具用於院內營養配方試算與臨床決策輔助。試算結果應結合病人實際病況、檢驗數據、液體限制、電解質狀態、吞嚥與腸胃道耐受性，以及醫師與營養師的專業判斷後使用。
