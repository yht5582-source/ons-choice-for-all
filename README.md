# 院內口服／管灌營養品處方台

中國醫藥大學北港附設醫院臨床營養用的單頁工具。依病人體位、照護情境、餵食途徑與疾病，計算熱量、蛋白質與水分目標，扣除病人目前自行吃進去的部分，再從院內現有營養品自動組出 3 個處方方案，可逐項調整後複製醫令文字。

線上版：<https://yht5582-source.github.io/ons-choice-for-all/>

## 功能

- **需求計算**：理想體重（院內公式或 BMI 22）、自動選用實際／校正／乾體重；熱量、蛋白質依 ESPEN、KDOQI、NPIAP 指引分情境設定，可手動覆寫。未透析 CKD 會把蛋白質壓在上限內（急性病或重症例外）。
- **經口攝取扣除**：輸入目前飲食約達需求的百分比，營養品只補缺口。
- **自動組合處方**：從院內 41 項品項中，依目標達成率、品項是否適合此病人（疾病、途徑、限水、血鉀血磷、劑型、供應方式）、份數與容量評分，列出 3 個不同主品項的方案。
- **處方檢核**：熱量、蛋白質達成率，容量與限水，鈉、鉀、磷合計，品項與疾病不符的警示，口服營養補充最低量。
- **灌食安排**：管灌餐數與每餐容量、另給水量；空腸管改連續灌食速率；重症與再餵食高風險的起始量。
- **營養風險**：GLIM 營養不良表現型與病因、NICE CG32 再餵食症候群風險。
- **院內品項表**：每項附營養成分、供應方式、查證來源與可信度。

## 檔案

- `index.html`：整個應用程式。計算引擎在 `/*ENGINE-START*/ … /*ENGINE-END*/` 之間，品項資料在其中的 `/*DATA-START*/ … /*DATA-END*/`。
- `tests.cjs`：引擎規則測試，執行 `node tests.cjs`。

## 品項資料

品項依臨床營養科「院內營養品（管灌與自費）」清單（115.08.07 更新）。營養成分於 2026-10-04 逐項上網查證廠商台灣官網或包裝標示圖，每項記錄來源網址與可信度（高／中／低）。以下品項需院內確認實際版本：

- 益力壯經典 22g／66g、益力康 22g／67g：官方無此克數標示，由每 100 g 換算。
- 補体康：假設為粉狀均衡配方。
- 補体康LPF：採用「補体康低蛋白營養配方」240 mL 罐。
- 速養療：數值為瓶裝每 10 g；院內若為 15 g 隨手包請確認。
- 飲沛空腹期營養：查不到公開標示。

更新品項時，修改 `P` 陣列中的對應物件即可；畫面上的選單與品項表都由同一份資料產生。

## 臨床使用聲明

本工具供院內醫療與營養專業人員試算與流程輔助使用，不取代營養師評估與臨床判斷。廠商可能改配方，開立前請以實際包裝標示為準。輸入資料只存在使用者瀏覽器，不會上傳。
